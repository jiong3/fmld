# Free Mandarin Learner's Dictionary

**maturity: alpha**

License: CC BY-SA 4.0 (Attribution-ShareAlike 4.0 International)

Based on the English-Chinese Wiktionary: https://en.wiktionary.org/

Wiktionary data imported from https://kaikki.org (January 2025)

Also contains data from MDBG/CEDICT: https://www.mdbg.net/chinese/dictionary

## Features

- two interchangeable formats: human editable text and sqlite database
    - text format lives in the repository and is checked by the tool using github actions
    - sqlite is generated by the tool
- cross-references between words and definitions, e.g. for synonyms, antonyms, measure words, ...
- examples sentences
- possibility to add additional information to words, definitions, cross-references, pronunciations and sentences:
    - notes with further explanations
    - any number of tags, e.g. to indicate relevance or highlight differences between usage in China and Taiwan
    - comments (meta information for editors or developers, not for users of the dictionary)
- constant, unique IDs for definitions, notes and example sentences
    - internal and external links to definitions, e.g. to provide examples sentences for a specific definition
    - possibility to add (initially automatic) translations
- two sections
    1. "learners section" at the beginning is roughly sorted by frequency and contains words particularly relevant to learners
        - < 20k words
        - relevant words are all words from vocabulary lists of text books, standardized tests, etc.
        - prioritized for manual corrections and LLM enhancements
    2. "extended section" starts from the word "%" and is sorted by the codepoint of the first character
        - all words not in the "learners section" with no upper limit

### Word Classes

The current word classes (parts of speech) are taken over from the wiktionary data.

- character: used for all characters and should be replaced with a proper class if the character is used independently as a word
- pron: pronoun
- noun: noun
- verb: verb
- verb-object: verb with separable object
- adj: adjektive
- adv: adverb
- intj: interjection
- conj: conjunction
- prep: preposition
- particle
- pattern: used for grammar patterns and always include ……
- phrase: figure of speech, grammar pattern (blanks indicated by ……), longer expressions
- name: of a place, person, country, etc.
- classifier: classifier or measure word
- det: determiner
- num: number
- postp: postposition
- proverb: proverb or chengyu
- prefix
- suffix

### Variants

Some Chinese words and characters have variants. The general idea is to pick one of the variants as the standard for this dictionary and list the other options as variants.

There are three options for handling variants in the dictionary:
1. pronunciation and all meanings are the same:
  - listed on the same line as the standard word in the text format, separated by semicolon
  - separate word entry in the database which links to the word entry of the standard word
2. pronunciation and some meanings are the same:
  - Xv reference to link the corresponding definitions
3. pronunciation is different
  - XV reference

#### Traditional

- different versions without difference in meaning or pronunciation
  - pick one and use it consistenly, ideally the standard variant is the simplest or most common one (easiest for learners)
  - Examples: 裡 instead of 裏
- different versions with some difference in meaning
  - split into two separate word entries and link them with XV
  - Example: 諮／咨 and 咨
- traditional character has a simplified version, which is also a different traditional character
  - split into two separate word entries and link them with XV

#### Simplified

Due to the simplification, there are much less variants among simplified characters.

- different simplified versions without difference in meaning or pronunciation
  - pick one and use it consistently
  - Examples: 沉靜／沉静;沉靜／沈静;沈靜／沈静
- same traditional character has different simplifications, based on the meaning
  - split into two separate word entries and link them with XV
  - 2 cases: 覆／复 - 覆 and 著／着 - 著

#### Open Questions

Currently there is no consistent approach how to propagate character variants to the words which contain those characters.

## LLM Usage

### Code

Many functions in the rust code, especially the SQL queries, are generated by an LLM (Google Gemini) using explicit requests. No agentic workflow was used.

### Dictionary

LLMs are used to:
- create references between words and definitions
- add tags to existing data
- generate example sentences, including word segmentation and translation

LLMs are not used to write definitions or notes. A multi-step, multi-prompt, multi-model approach is used to minimize mistakes whenever possible.

All items for which LLMs have been used are tagged with 'a' (ai-partly) or 'A' (ai-only). Those tags can be removed after additional verification.

The prompt templates are in /rust/docs/llm_prompts.toml, the functions to generate the prompts in /rust/db_llm_prompts.rs.

The results were merged using Python scripts which are not found in the repository. The functions to import the merged results are in /rust/db_edit_once.rs.

#### Synonyms

The original Wiktionary data contains pairs of synonyms. LLMs were used to identify the corresponding definitions.

An additional source of synonyms was generated by an LLM (gpt-4o) using a multi-step process (not part of this repository):
- Request an example sentence in traditional characters with an English translation for a Chinese word and one English definition
- Remove the word for which the example was requested from the sentence
- Ask the LLM to provide a list of words which could be used to fill in the blank
- If the list contains the word from the original request and also another word in multiple cases, the other word is identified as a possible synonym

References based on Wiktionary data are tagged with 'a', those based on LLM derived synonyms with 'A'.

Prompt template: match_synonym_definitions

Used LLMs:
- Mistral: mistral-large-latest
- OpenAI: gpt-4.1-2025-04-14
- Anthropic: claude-sonnet-4-5-20250929

The slightly cleaned up results from the LLMs are available in /data/llm_out_syn_pairs.csv, the columns corresponding to:
- word A traditional
- word A simplified
- word A definition id
- word B traditional
- word B simplified
- word B definition id
- similarity score (1-4, see prompt template)
- how often this word pair appeared in LLM generated synonyms
- how often this word pair appeared in Wiktionary data
- model provider
- explanation of the differences by the LLM‚

The results involving single characters have been merged for those definitions identified as potentially "active", see "Active Definitions".

Results from the three models were merged using the following criteria:
- discard any results with a score >= 4
- add a definition pair if two models agreed on one pair
- don't add references from one definition to two definitions of the other word, pick the one with the lower score in that case


#### Antonyms

The original Wiktionary data contains pairs of synonyms and antonyms. LLMs were used to identify the corresponding definitions. The resulting references are tagged with 'a'.

Prompt template: match_antonym_definitions

Used LLMs:
- Mistral: mistral-large-latest
- OpenAI: gpt-4.1-2025-04-14
- Anthropic: claude-sonnet-4-5-20250929

The slightly filtered and cleaned up results from the LLMs are available in /data/llm_out_syn_pairs.csv, the columns corresponding to:
- word A traditional
- word A simplified
- word A definition id
- word B traditional
- word B simplified
- word B definition id
- type of antonym (see prompt template)
- model provider
- explanation for the chosen type (not very useful)

The results involving single characters have been merged for those definitions identified as potentially "active", see "Active Definitions".

Results from the three models were merged using the following criteria:
- discard any results with a type == 4 (not an antonym)
- add a definition pair if two models agreed on one pair


#### Collocations

The references with collocations which could be confirmed by subtitle data are tagged with 'a', all others with 'A'.

##### 1. Generation

Collocations were derived from output of LLMs and if possible validated using a corpus of around 5M lines of subtitles from movies and TV shows using Mandarin as a native language.

Prompt template: find_collocations

Used LLMs:
- Mistral: mistral-large-latest
- OpenAI: gpt-4.1-2025-04-14
- Anthropic: claude-sonnet-4-5-20250929

The LLMs were requested twice (with different word order) to provide up to 10 collocations for all words in the "learners section" which have at least one definition with one of the following word classes:
"noun", "verb", "verb-object", "adj", "adv", "phrase"

Generated collocations were removed unless:
- they are confirmed by subtitle data and appeared at least 2 times in the LLM proposals
- they are not single character words and appeared at least 4 times in the proposals of at least 2 LLM models

##### 2. Matching

In order to create definition-level references, the LLMs were tasked to find the definition pairs which best match the idiomatic usage.
Only collocations which have definitions in the dictionary could be included.

Prompt template: match_collocations

Used LLMs:
- Mistral: mistral-large-latest
- OpenAI: gpt-4.1-2025-04-14
- Anthropic: claude-haiku-4-5-20251001

The definition id of the word and its collocation had to be confirmed by at least two LLMs, otherwise no reference was generated.
As an exception to this condition, a collocation was still used as a reference target without a definition id if no definition id could be determined, but the collocation was confirmed by subtitle data. 

Whether a collocation usually appears before or after the word is determined by the subtitle data or, as a second priority, based on the order in the example sentences which were requested by the prompt.

If word + collocation or collocation + word exist as an entry in the dictionary, a "part-of" reference (X<) was created instead of the collocation reference.


#### Word Decompositions

Words can be broken down into smaller words or single characters. LLMs were used to identify the best breakdown of each word in the "learners section" into components. If possible, the link should be to the most fitting definition of each component.

Prompt template: match_decomposition

Used LLMs:
- Mistral: mistral-medium-latest
- OpenAI: gpt-4.1-2025-04-14
- Anthropic: claude-sonnet-4-5-20250929


#### Active Definitions

The wiktionary data includes many definitions for words and especially characters without indication of the relative significance. Since Chinese learners need a way to know which definition should be actually learned as active vocabulary, LLMs were used, in combination with data from subtitles, to identify the most important definitions. Avoiding false positives was more important than avoiding false negatives for this task, meaning there will be some important definitions which are not yet tagged and hopefully few definitions which got a tag and are actually not used in spoken language.

##### 1. Characters

The LLM was used to preselect definitions of characters when they are used as stand-alone words. As a byproduct, example words for bound-form definitions are also generated.

Prompt template: identify_stand_alone_definitions_of_chars

Used LLMs:
- OpenAI: gpt-5-mini (2x, once accidentally without system prompt)

If the model output the single character for a definition in both runs, this definition would be included as a candidate.

The example words were added to character definitions with the 'A' (ai-only) tag if they could be confirmed by results from the decomposition prompt described above.

##### 2. Words

The LLM was used to preselect definitions of words which can be considered modern, standard, spoken Mandarin in China or Taiwan.

Prompt template: identify_spoken_definitions_of_words

Used LLMs:
- OpenAI: gpt-4.1-2025-04-14
- Mistral: mistral-medium-latest

If both models classified a definition as standard, this definition would be included as a candidate.

##### 3. Usage in Subtitles

The LLM was used to identify definitions used in excerpts subtitles from movies and TV series. For each definition, 10 excerpts of three lines are included in the prompt, maximum around a 100 excerpts. The second line always contains the word of interest, for which the definitions are also included in the prompt.

Prompt template: identify_definitions_in_subtitles

Used LLMs:
- OpenAI: gpt-4.1-2025-04-14
- Mistral: mistral-medium-latest

If both models identify the same definition in the same excerpt and the definition is a candidate according to step 2 or 4, this definition is tagged as a candidate for active vocabulary (tag '*', or '+' if it's the only definition of the word).


#### Classifiers / Measure Words

The wiktionary data already contains classifiers, but there were still many nouns without any.

Prompt template: find_classifiers

Used LLMs:
- Mistral: mistral-large-latest
- OpenAI: gpt-4.1-2025-04-14
- Anthropic: claude-sonnet-4-5-20250929

For all nouns (excluding single characters which still have the class "character"), a list of classifiers was requested from the LLMs two times, in different orders.
If a classifier was suggested at least 5 out of 6 times for a specific definition, the classifier was added to the dictionary with the tag 'A'.


#### Example Sentences

Two sources were used for example sentences, the wiktionary data and sentences generated as part of the collocation matching using LLMs.

Prompt template: identify_good_sentences

Used LLMs:
- Mistral: mistral-medium-latest
- OpenAI: gpt-4.1-2025-04-14
- Anthropic: claude-sonnet-4-5 and 4-6

Sentences from the wiktionary were excluded if:
- 2 out of 3 models classified it as not good
- any word was not found in the FMLD
- it was shorter than 4 words or longer than 18 words
- the words joined together were an entry in the FMLD
- the explanation of at least one model contained certain keywords like "dialect", "poetry", "uncommon", "classical", "文言文" etc.

If the same sentence is used for several different definitions in the wiktionary, it will only be added once to the FMLD, but still include all the definition ids.

Sentences generated by LLMs were excluded if:
- any model classified them as not good
- any word was not found in the FMLD
- the corresponding collocation pair was tagged 'A', but collocations with tag 'a' are also available for the relevant definition
- another sentence for that collocation pair with a higher probability of being "graded" was available.

The word segmentations provided by all models were merged, with a preference for longer words. English translations were picked from the model reponses using the following priority: Claude Sonnet, Gpt-4.1, Mistral Medium. As a result, almost all translations are coming from Claude Sonnet.

In general it was attempted to provide as many "graded" sentences as possible, meaning that all words in the sentence appear in the dictionary before the word for which the sentence is provided as an example.

Sentences from the wiktionary were tagged with 'a' (word segmentation and translation was done by LLMs), generated ones with 'A' (everything by LLMs).
